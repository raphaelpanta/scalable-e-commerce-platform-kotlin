# notification

Service for the bounded context **notification**, generated by `./gradlew newService -Pname=notification` from the
layout of the reference service [`services/catalog`](../catalog/README.md). It carries no business logic
yet: the placeholders `BoundedContext` (domain) and `DescribeService` (application) are there so every
convention has something to check; replace them with the first real domain type and use case.

Package root: `com.ecommerce.notification`.

| Layer | Where | Run alone |
|---|---|---|
| unit | `domain/src/test`, `application/src/test`, architecture rules in `infrastructure` | `./gradlew -q :services:notification:domain:test` |
| integration | `infrastructure/src/integrationTest` (Testcontainers PostgreSQL) | `./gradlew -q :services:notification:infrastructure:integrationTest` |
| contract | `infrastructure/src/contractTest` (Pact consumer in `contractTest`, provider tagged `provider` in `contractVerify`) | `./gradlew -q :services:notification:infrastructure:contractTest :services:notification:infrastructure:contractVerify` |
| acceptance | `infrastructure/src/acceptanceTest` (Cucumber) | `./gradlew -q :services:notification:infrastructure:acceptanceTest` |

Running: `NOTIFICATION_DB_HOST` (default `localhost`), `NOTIFICATION_DB_USER` and `NOTIFICATION_DB_PASSWORD`, then
`./gradlew -q :services:notification:infrastructure:bootRun`. Health on `http://localhost:8081/actuator/health`.
