# order

Service for the bounded context **order**, generated by `./gradlew newService -Pname=order` from the
layout of the reference service [`services/catalog`](../catalog/README.md). It carries no business logic
yet: the placeholders `BoundedContext` (domain) and `DescribeService` (application) are there so every
convention has something to check; replace them with the first real domain type and use case.

Package root: `com.ecommerce.order`.

| Layer | Where | Run alone |
|---|---|---|
| unit | `domain/src/test`, `application/src/test`, architecture rules in `infrastructure` | `./gradlew -q :services:order:domain:test` |
| integration | `infrastructure/src/integrationTest` (Testcontainers PostgreSQL) | `./gradlew -q :services:order:infrastructure:integrationTest` |
| contract | `infrastructure/src/contractTest` (Pact consumer in `contractTest`, provider tagged `provider` in `contractVerify`) | `./gradlew -q :services:order:infrastructure:contractTest :services:order:infrastructure:contractVerify` |
| acceptance | `infrastructure/src/acceptanceTest` (Cucumber) | `./gradlew -q :services:order:infrastructure:acceptanceTest` |

Running: `ORDER_DB_HOST` (default `localhost`), `ORDER_DB_USER` and `ORDER_DB_PASSWORD`, then
`./gradlew -q :services:order:infrastructure:bootRun`. Health on `http://localhost:8081/actuator/health`.
